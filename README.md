# dawin_photo_template

다윈서비스 법정의무교육 사진 증빙 PDF 만들기 페이지 (GitHub Pages)

과목별로 휴대폰 갤러리 사진을 넣으면, 과목 제목과 교육일자가 들어간 증빙 양식(A4, 한 쪽에 사진 2장)으로 PDF를 만들어 내려받습니다.

## 기본 과목

1. 직장 내 장애인 인식개선 교육
2. 개인정보보호 교육
3. 직장 내 성희롱 예방 교육
4. 직장 내 괴롭힘 예방 교육
5. 근로자 안전보건 교육

사진을 넣지 않은 과목은 PDF에서 자동으로 빠집니다. 과목 제목 수정, 추가, 삭제는 화면에서 바로 할 수 있습니다.

## 과목 목록 바꾸기

`index.html`에서 `const DEFAULTS=[` 로 시작하는 줄의 제목을 고치면 됩니다.

## 개인정보

사진은 이용자 휴대폰 브라우저 안에서만 처리되며 서버나 이 저장소로 전송되지 않습니다. 이 저장소에는 고객사 사진이나 완성된 PDF를 올리지 않습니다.
